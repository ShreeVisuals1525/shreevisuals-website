# ShreeVisuals Website

A responsive three-page static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — Home
- `services.html` — Services & Pricing
- `portfolio.html` — Portfolio, testimonial placeholders and contact form
- `styles.css` — Shared styling and responsive layouts
- `script.js` — Mobile navigation, current year, and email-draft contact form

## Preview locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Important contact behavior
- WhatsApp links open `https://wa.me/919789298085`.
- Email links open a draft to `shreevisualz@gmail.com`.
- The contact form opens an email draft containing the submitted details. The visitor must press Send in their email app. It does not send automatically or store submissions.

## Before publishing
1. Replace the portfolio placeholder visuals with your actual project thumbnails.
2. Update each portfolio link to your real public project URL.
3. Replace testimonial placeholders only with genuine client feedback and permission to publish it.
4. Check the phone number and email address.
5. Preview on mobile and desktop.

## Free publishing with GitHub Pages
1. Sign in or create an account at GitHub.
2. Create a new public repository, e.g. `shreevisuals-website`.
3. Upload all five website files to the repository root.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”.
6. Select the `main` branch and `/ (root)` folder, then Save.
7. Wait for GitHub Pages to publish and open the provided website URL.

Alternative: Netlify's free tier can also host a static site by uploading the website folder using its supported deployment flow. Plan limits can change.

## Customization
Edit text in the HTML files, adjust colors near the top of `styles.css` under `:root`, and change links by editing the relevant `href` attributes.
